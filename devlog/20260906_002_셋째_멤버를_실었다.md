셋째 멤버로 굽고 GCP 에 얹는 것 — 을 끝냈다. **재배포 없이** 화면이 3자

## 한 것

1. `scripts/make_full224.py` 로 **격자 `v3-full224`** 를 이 기계에도 세웠다
   (7,912장 · 224px · 24장은 128 확대 — 2080ti 와 같은 길).
2. megad 얼린 임베딩 → `--fit-all --unfreeze 16 --backbone megad`
   (left 61개체·587조각 / right 60개체·713조각) → 명령이 시킨 대로
   `--deep` 임베딩 7,912장 (209초).
3. `emb-megaL.npz`(46MB) · `cls-megaL.npz` 를 GCP `reid/v3/` 에 넣고
   **`ensemble.json` 을 세 멤버로 다시 썼다** — 이 파일의 주인은 인수인계대로
   이제 이쪽이다.
4. 연기 시험: 운영 컨테이너 안에서 `_reid_pool()` 이 **멤버 셋을 전부 연다**
   (fullL 1024 · cropL 1024 · megaL 1536 · 좌 61/우 60). `.blocks.pt`(1.3GB)
   는 이 기계에만 둔다.

## 유보를 같은 날에 닫았다 — 89.9

2080ti 가 로짓 두 벌을 GCP `reid/logits/` 에 올려 주어(자: 폴드 5 · 씨앗 1 ·
`--as-of 2168` · 화면 격자 차례), megad 갈래를 **같은 자로 다시 재고**
(단독 81.2 — GCP 의 살아 있는 DB 사본으로 as-of 2168 을 맞췄다)
`reid_ensemble` 로 셋을 합쳤다:

    전체 L 84.1  ·  크롭 L(새 레시피) 87.6  ·  megad 81.2
    →  배포된 3자 앙상블 = **top-1 89.9 · top-5 96.7 · top-10 97.6**

화면과 같은 함수(`reid.ens_logits`)로 잰 값이라, **화면이 지금 내는 것이
이 성적이다.** 옛 크롭 3자(89.8)·새 크롭 2자(89.0)를 둘 다 넘었다 —
계보 셋(웹 자기지도 전체 · 같은 백본 크롭 · 야생동물 ArcFace)이 표를 가른다.
로짓은 GCP `reid/logits/` 에 세 벌이 모여 있고 README 에 결과를 적었다.

곁가지: 같은 명령의 1차 실행이 한 시간을 돌고 **아무 출력 없이** 죽었다
(원인 미상 — grep 파이프라인은 SIGKILL 을 조용히 삼킨다). 날 로그 + 종료코드
기록으로 재실행해 잡았다. 긴 칸은 필터 없이 파일로 받는 것이 맞다.
