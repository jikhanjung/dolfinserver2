# devlog 색인

개발 로그·계획 문서 색인. **파일명 slug 자체가 요약**이라 디렉토리 listing 이
1차 인덱스이고, 이 문서는 번호 규칙과 주의사항을 더한다.

## 명명 규칙

- **작업 기록**: `YYYYMMDD_{nnn}_{title}.md` (001부터 단조 증가)
- **계획 문서**: `YYYYMMDD_P{nn}_{title}.md` (P01부터)
- **리뷰 문서**: `YYYYMMDD_R{nn}_{title}.md` (R01부터)

**본문은 무엇을 했는지보다 왜 그렇게 했고 무엇을 버렸는지를 적는다.**
버린 안과 그 이유가 남아야 같은 실패를 다시 시도하지 않는다.
