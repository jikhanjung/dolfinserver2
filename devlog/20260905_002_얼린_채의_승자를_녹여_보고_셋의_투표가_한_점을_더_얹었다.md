## 1. `split()` 이 Swin 을 가른다

MegaDescriptor(timm Swin-L)는 단계 넷(블록 2·2·18·2 · 다운샘플이 각 단계
**앞**에 선다)이라 ViT 의 "뒤에서 N블록"이 그대로 안 됐다. 단계들을 한 줄로
펴서(다운샘플 → 블록들) 뒤에서 N블록부터 배우는 갈래를 붙였다 — 자른 자리
뒤에 낀 다운샘플(patch merging)은 함께 배운다. **등가를 재어 확인했다**:
절단점 셋(2·6·20)에서 가른 forward 가 원본 `m(x)` 와 최대 차이 0. `reid_cls`
쪽은 셋을 고쳤다 — ViT 전용 검사에 timm 허용 · 캐시 보간 크기를 백본에 묻기
(megad 는 384) · 특징 폭을 `num_features` 로 (Swin 은 `embed_dim` 이 줄기
폭 192 라 다르다). 커밋 `9aac672`.

## 3. 셋의 투표 — 상보성의 조건이 정확해졌다

`20260903_001` 의 "약한 멤버를 섞으면 희석된다(셋·넷 < 둘)"에 단서가 붙는다.
그때의 셋째는 **약한**(76.8) 크롭 B 였다. **동급이면서 사전학습 계보가 다른**
셋째는 다르다:

```
전체 L + 크롭 L (기존 챔피언)        89.2 ± 0.5
전체 L + 크롭 L + megad          **89.8 ± 0.1**   ← 폭도 5배 좁다
넷 (+크롭 B 76.8)                  89.7 ± 0.2     ← 약한 넷째는 도로 내린다
전체 L + megad                     87.6           크롭 L + megad  88.9
```

멤버 셋의 계보가 서로 다 다르다 — 웹 자기지도(DINOv3) 전체 조각 · 같은 백본
크롭 · 야생동물 ArcFace(Swin). **앙상블의 조건은 "수"도 "각자의 성적"만도
아니고, 동급 + 다른 실수다.** 폭이 ±0.1 로 준 것도 투표자가 늘어난 효과다.
