도표 한 장으로도 있다 — https://claude.ai/code/artifact/918fa1ec-84cd-4af4-a116-f239c43e1114

**끝 그림: 전체 조각 DINOv3-L + 뒷날 크롭 DINOv3-L 의 로짓 평균 =

## 1. DINOv3-L — 곡선을 한 칸 간격으로 다 그렸다

가중치 4종(S·S+·B·L)을 라이선스 링크로 받아 두었던 것 중 L(303M · 24블록 ·
1024차원)을 열었다. 격자 v3-224, 블록을 8부터 20까지:

```
블록    0     8    12    13    14    15    16    17    18    20
     55.5  78.9  82.8  83.1  84.6  84.9  84.6  84.5  84.5  84.0
폭          ±.8   ±.1   ±.6   ±.4   ±.5   ±.4   ±.9  ±1.5  ±1.0
```

- **계단은 13→14 사이에서 올라서고, 14~18 이 84.5~84.9 의 고원**이다.
  씨앗 폭을 감안하면 고원 안의 순위는 잡음이다 — 배포 모델은 이 구간
  아무 데서 떠도 같고, 계산이 덜 드는 14 쪽을 골라도 손해가 없다.
- 얼린 채(55.5)도 얼린 칸 신기록이었다 — 용량이 얼린 특징의 질도 올린다.
- B의 "8블록 꼭짓점"을 비율(3분의 2)로 옮긴 예측이 대략 맞았다 — 16 근처.

## 2. 크롭 × L — 크롭의 이득이 용량과 반비례해 사라진다

```
크롭 꼭짓점의 이득 (전체 조각 꼭짓점 대비)
  DINOv2-S  +2.8   ·   DINOv2-B  +1.5   ·   DINOv3-B  +0.5   ·   DINOv3-L  −0.6
```

크롭 × L 은 어느 깊이에서도 전체 조각 L 을 못 넘었다 (꼭짓점 16블록 84.0
대 84.6). 크롭의 본질이 "notch 를 백본이 볼 수 있게 화소 예산을 몰아주는 것"
인데, **L 은 전체 조각에서도 notch 를 스스로 캔다** — 크롭은 더해 주는 것
없이 앞날·전체 실루엣을 버리는 비용만 남는다. `20260902_001` 의 "패치 천장"
이야기가 용량 축에서 닫힌 셈이다.

## 3. 앙상블 — 수가 아니라 상보성이다

`--save-logits`(전날 붙인 것)로 네 챔피언의 질의별 로짓을 저장하고, 표준화
후 평균해 같은 자로 채점했다.

```
                                  top-1        top-5   top-10
전체 L·16 단독                    84.6 ±0.4    94.4    96.5
크롭 L·16 단독                    84.0 ±0.6    93.9    95.9
────────────────────────────────────────────────────────────
전체 L + 크롭 L                 **89.2 ±0.5**  95.9    97.3   ← 끝 그림
전체 L + 크롭 B(76.8)             86.4 ±0.2    95.2    96.9
셋 (L 둘 + 크롭 B)                88.0 ±0.3    95.8    97.1
넷 전부                           88.1 ±0.4    96.0    97.3
전체 B + 크롭 B (전날 B끼리)       82.8 ±1.0    94.1    96.3
```

- **동급으로 강한 두 시각(전체 모양 + 뒷날)의 짝이 최강**이고, 약한 멤버를
  더 섞으면 희석된다 (셋·넷 < 둘). 크롭이 단독으로는 L 에서 졌지만(2절)
  **앙상블 멤버로는 +4.6 을 보탠다** — 다른 실수를 하기 때문이다.
- **가중치는 지렛대가 아니다** — 전체 L 가중 0.45~0.60 이 89.0~89.2 로
  평평하다. 반반이 곧 꼭짓점이고, 비율에 둔감한 것 자체가 배포에 좋은
  성질이다 (재는 날을 훔쳐보며 비율을 고를 이유가 없다).
- 크롭 갈래를 배포에 넣으면 새 조각마다 크롭판도 함께 떠야 한다 —
  `items.json` 좌표만으로 파생되므로 파이프라인 한 단계다 (`20260902_001` 3절).

## 4. MegaDescriptor — 얼린 갈래의 승자 (기록만, 2026-09-02 저녁 실측)

동물 re-ID 전용 사전학습(WildlifeDatasets · Swin-L-384 · ArcFace)을 timm
갈래(`megad`)로 붙였다. **얼린 채**:

```
              kNN     선형
격자 v3-128   47.3    60.1
격자 v3-224   51.9    64.3   ← 384 입력 백본에는 진짜 224 화소가 실린다
크롭(v3-te)   38.5    54.6   ← 전신 크롭으로 배운 모델이라 크롭 분포가 낯설다
```

kNN 51.9 는 DINOv2-S 의 **선형**(49.5)보다 높고, 얼린 선형 64.3 은 백본에
손 안 대고 옛 챔피언(DINOv2-B 2블록 64.3)과 동률이다. 도메인 사전학습의
전이가 실증됐다. **녹이는 길은 Swin 이 단계 구조라 `split()` 에 갈래를 새로
짜야 한다** — L 이 84.9 를 낸 지금은 급하지 않지만, "얼린 채 배포"가 필요한
자리(가벼운 기계)에는 이것이 답일 수 있다.
